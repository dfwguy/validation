# Runbooks

Step-by-step operational procedures for executing validation activities in the lab and on customer systems. Runbooks complement the formal MOPs in [validation-mops](../validation-mops/) — MOPs define *what* to validate and the pass/fail criteria; runbooks capture *how to actually run it* on a specific platform, including the gotchas that bite the next operator.
